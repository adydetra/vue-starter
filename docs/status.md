# Project Status & Roadmap

Current state, supported features, and technical notes for `vue-starter`.

## Implemented Scope

- **Vue 3 + Vite 8**: Fast HMR development environment powered by Vite.
- **TypeScript & Type Checking**: Full TypeScript support with `vue-tsc` type-checking in the build script.
- **Tailwind CSS v4**: Zero-config Vite integration via `@tailwindcss/vite`.
- **Atomic Design Components**: Example implementation including `SpotlightCard`, `TechStackCard`, and `TheExample`.
- **Routing & State**: Configured with `vue-router` and `pinia`.
- **ESLint & Code Standards**: Managed by `@antfu/eslint-config`.

## Roadmap

- [ ] Vitest component unit tests with `@vue/test-utils` and `happy-dom`.
- [ ] GitHub Actions CI workflow for automated linting and build checks.
- [ ] Dark/Light mode theme switching utility.
